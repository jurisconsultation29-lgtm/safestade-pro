Empreinte SHA-256 + horodatage, chaque preuve référence la précédente (façon blockchain simplifiée) — infalsifiable sans casser la chaîne
🔑 Chiffrement (AES-256)RÉEL — Web Crypto
Différence avec le hachage : le hachage est à sens unique (jamais retrouvable), le chiffrement est réversible avec la bonne clé — utile pour protéger un contenu, pas juste vérifier son intégrité.
